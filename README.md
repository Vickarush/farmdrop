# FarmDrop

FarmDrop is a web platform that connects farmers directly to buyers.
Farmers can list their produce, buyers can browse and order, and
orders are managed in one simple system.

Built to solve a real Kenyan problem: farmers struggle to find
reliable buyers, and buyers struggle to find fresh produce at a
fair price.

## Features

- Farmer produce listings with prices and quantities
- Buyer browsing and ordering
- Order management dashboard
- Responsive design for mobile and desktop
- Clean, simple UI for farmers and buyers

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript, Tailwind CSS, React
- Backend: PHP / Python
- Database: PostgreSQL / MySQL
- Other: REST APIs, Git
